# Semantic Rules
Rule             | Logic
Data:Minimality  | Only record the highest level achieved.
Activity:Logic   | If "Upgrading", active research = CurrentLevel + 1.
Rule:SafetyValve | The Notes column is mandatory to prevent truncation.
Rule:MaxLevel    | CurrentLevel must not exceed MaxLevel in global files.
