========================================================= 
BUILDING DATA TABLE 
=========================================================
The Building Data Table is used to estimate build times for the construction of buildings
This Building Data Table subclasses the Table format section in the Specification.

1. Schema Name
• Schema: BuildingData

2. Required Header Fields
The following exact header fields must appear:
• Name:
• Version:
• Scope:
• Format: Table
• Schema: BuildingData

3. Column Definitions
The Label Row must contain the following columns exactly, and validators must enforce these types:
BuildingName = String
TargetLevel = Integer
OriginalTime = String
Food = ScaledInt
Iron = ScaledInt
Coin = ScaledInt
Oil = ScaledInt
HeadquartersLevel = Integer
BuildingRequirements = List(Pair(BuildingID, Level), sep=";", kv_sep=":", logic_op="|")

4. Semantic Rules
• Rule: TargetLevel must be greater than 0.
• Rule: All resource costs (Food, Iron, Coin, Oil) must be non-negative.
• Rule: HeadquartersLevel must be a valid integer.

5. Optional Additional Columns:
• Notes: String
