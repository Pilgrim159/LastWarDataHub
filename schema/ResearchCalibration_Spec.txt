=========================================================
RESEARCH CALIBRATION TABLE SPECIFICATION
=========================================================
The Research Calibration Table is used to track and verify player-specific 
research time reduction multipliers for various tech trees.

This Research Calibration Table subclasses the Table format section in the Specification.

1. Schema Name
• Schema: ResearchCalibration

2. Required Header Fields
The following exact header fields must appear to identify the player and calculation rules:
• Name: String
• TreeID: Research_Calibration
• Version: String
• Scope: Account
• Format: Table
• Schema: ResearchCalibration
• PlayerName: String
• Rule: Multiplier = Float
• Rule: UpgradeTime = Calculation (e.g., Ceiling(OriginalTime / Multiplier))

3. Column Definitions
The Label Row must contain the following columns exactly:
• TreeID = String (The unique identifier for the tech tree, e.g., Age_of_Oil)
• NodeID = String (Unique identifier for the research node)
• NodeLevel = Integer (The specific level being upgraded to)
• OriginalTime = Duration (The raw base research time)
• UpgradeTime = Duration (The actual time reported in-game)

4. Semantic Rules
• Rule: UpgradeTime must be mathematically less than or equal to OriginalTime.
• Rule: The Multiplier defined in the header must consistently resolve the difference between OriginalTime and UpgradeTime across all rows.
