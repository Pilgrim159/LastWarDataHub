=========================================================
RESEARCH CALIBRATION TABLE SPECIFICATION
=========================================================
The Research Calibration Table is used to track and verify player-specific 
research time reduction multipliers for various tech trees.

1. Schema Name
• Schema: ResearchCalibration

2. Required Header Fields
• Name: String
• ResearchID: Research_Calibration (Identifies this specific calibration document)
• Version: String
• Scope: Account: <AccountID>                
• PlayerName: String            
• Format: Table
• Schema: ResearchCalibration
• Rule: Multiplier = Float
• Rule: UpgradeTime = Floor(OriginalTime / Multiplier)

3. Column Definitions
The Label Row must contain the following columns exactly:
• TreeID = String         (Identifies the source tree: e.g., Age_of_Oil)
• NodeID = String         (The research node name)
• NodeLevel = Integer     (The level being calibrated)
• OriginalTime = Duration  (Base time from global tech files)
• UpgradeTime = Duration   (Actual time from player tech center)

4. Semantic Rules
• Rule: UpgradeTime must be mathematically less than or equal to OriginalTime.
• Rule: The Multiplier must resolve the UpgradeTime using the formula defined in the header.
